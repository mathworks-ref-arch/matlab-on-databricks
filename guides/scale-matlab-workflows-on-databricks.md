# Scale MATLAB Workflows on Databricks

To scale your MATLAB&reg; workflows on Databricks, choose from four approaches:

- If you want to scale MATLAB code interactively on a single node, you can use [Parallel Computing Toolbox&trade;](https://www.mathworks.com/products/parallel-computing.html).

- If you want to develop quickly using Spark in MATLAB, on a single node, MathWorks recommends you [Use Spark in MATLAB](./PSP%20docs/SparkInMATLAB.md).

- If you want to combine Spark with compiled MATLAB or Simulink code for quick development or testing in MATLAB, and want to scale performance-critical sections of your code across multiple nodes, MathWorks recommends you [Use Spark with Compiled MATLAB Code](./PSP%20docs/SparkWithCompiledMATLAB.md).

- If you want to scale production MATLAB or Simulink code across multiple nodes, run frequent or time-consuming computations, and run MATLAB code in Databricks notebooks, MathWorks recommends you [Scale Compiled MATLAB Code for Production Workflows](./PSP%20docs/ScaleCompilerSDK.md).
